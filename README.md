# Неоновый бестиарий — онлайн-выставка Юлии Деревцовой

**Сайт:** https://berengow.github.io/neon-bestiary/

Сообщество художницы: [vk.ru/tirannozavrrrsex](https://vk.ru/tirannozavrrrsex)

Статический сайт без сборки: `index.html` + `css/` + `js/` + `img/`.
Публикуется через GitHub Pages из ветки `main`: любое изменение,
отправленное в репозиторий, появляется на сайте через минуту-две.

## Как посмотреть
Откройте `index.html` двойным щелчком — сайт работает и без сервера.

## Как поменять названия, описания, технику и год
Всё лежит в одном файле — `js/data.js`. У каждой работы есть поля
`title`, `note`, `tech`, `year`. Пустые `tech` и `year` на сайте не показываются.
Поле `hall: true` означает, что работа висит в «Главном зале».

## Как добавить новую работу
1. Положите картинку в `img/full/15.jpg` (до 2000 px по длинной стороне)
   и уменьшенную копию в `img/thumb/15.jpg` (до 900 px).
2. Добавьте в `js/data.js` запись с `id: "15"` и реальными `w`/`h` картинки.

## Если сайт переедет на другой адрес
Замените в `index.html` адрес `https://berengow.github.io/neon-bestiary/`
(теги `canonical`, `og:url`, `og:image`) на новый — иначе во ВКонтакте и
Telegram у ссылки пропадёт картинка-превью.
