**Сайт:** https://berengow.github.io/neon-bestiary/

Сообщество художницы: [vk.ru/tirannozavrrrsex](https://vk.ru/tirannozavrrrsex)

Публикуется через GitHub Pages из ветки `main`: любое изменение,

## Что есть на сайте
- интро «открывающийся глаз» (один раз за визит, клик — пропустить);
- «Главный зал» — горизонтальная экспозиция, подсветка в цвет текущей картины, счётчик;
- коллекция: фильтры (в том числе «Новинки»), сортировка «Радугой», «Случайная работа»;
- лайтбокс: размытый фон в цвет картины, увеличение деталей, слайд-шоу,
  полноэкранный режим, лента миниатюр, прямые ссылки вида `#work-15`;
- живые глаза, которые следят за курсором и моргают;
- WebP-картинки с запасным JPEG, разметка schema.org, `sitemap.xml`, страница 404.

## Как посмотреть
Откройте `index.html` двойным щелчком — сайт работает и без сервера.

## Как поменять названия, описания, технику и год
Всё лежит в одном файле — `js/data.js`. У каждой работы есть поля
`title`, `note`, `tech`, `year`. Пустые `tech` и `year` на сайте не показываются.
Поле `hall: true` — работа висит в «Главном зале», `isNew: true` — метка «новое».
Порядок записей в списке = порядок на выставке; количество работ везде
пересчитывается само.

## Как добавить новую работу
1. Положите картинку в три размера — каждый в двух форматах, JPEG и WebP
   с одинаковым именем (WebP обязателен: без него в коллекции будет пустая карточка;
   сделать его можно, например, на squoosh.app):
   `img/full/23.jpg` + `.webp` (до 2000 px), `img/thumb/23.jpg` + `.webp` (до 900 px),
   `img/mini/23.jpg` + `.webp` (до 240 px).
2. Добавьте в `js/data.js` запись с `id: "23"` и реальными `w`/`h` картинки.

## Если сайт переедет на другой адрес
Замените адрес `https://berengow.github.io/neon-bestiary/` в `index.html`
(теги `canonical`, `og:url`, `og:image`), в `js/data.js` (поле `site`),
в `sitemap.xml`, `robots.txt` и пути `/neon-bestiary/` в `404.html` —
иначе во ВКонтакте и Telegram у ссылки пропадёт картинка-превью.
